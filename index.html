Fine-tuning study · Feb 2025

Teaching Llama 2 to answer questions about one university.

Students at Abdul Wali Khan University Mardan ask the same admissions and programme questions every term. I wanted to know how small a dataset could be and still shift a 7B model's behaviour, so I wrote 41 question–answer pairs by hand and fine-tuned on those alone.

It works for questions close to the training set and invents details for anything outside it. 41 pairs buys you tone and format, not knowledge. The honest fix is retrieval over the university's actual documents, which is what I would build if I started again.

Base model
Llama-2-7b-chat, loaded in 4-bit NF4
Method
QLoRA — rank 64, alpha 16, dropout 0.1
Training run
1 epoch, batch size 4, lr 2e-4, on a single Colab T4
Evaluation
Manual inspection only — no held-out set, which is the main gap

Generative reconstruction · 2024

Reconstructing a complete fingerprint from a partial image.

This project uses a Generative Adversarial Network to recover missing fingerprint information from partial images. The generator learns to reconstruct the missing detail while the discriminator learns to distinguish generated fingerprints from real ones.

Most of the practical work was in preprocessing and building a reproducible training workflow. The notebook covers dataset preparation, GAN training, image generation, model saving and loading, and evaluation rather than stopping at a generated example.

Computer vision project · 2024

Human Counting and Ethnicity Detection.

This project combines YOLOv8 detection and tracking with a video pipeline that counts people crossing a defined region. Persistent track IDs make it possible to count entries and exits without counting the same person once per frame.

I also implemented an ethnicity-detection experiment using DeepFace. The counting pipeline is a useful computer-vision task; the demographic classifier is not something I would deploy, so the case study documents both what worked and why I rejected part of the brief.

Real-time sign recognition · 2023

Recognizing hand signs from a webcam in real time.

This project turns webcam frames into hand-landmark features with MediaPipe, then classifies the normalized coordinates with a Random Forest model. OpenCV draws the landmarks, bounding box, and predicted sign back onto the live frame.

The training notebook collects and filters the landmark data, trains the classifier, and evaluates it on a held-out split before saving the model for live inference.

Multi-model video analysis · Oct 2026

Human Insight AI: one video interface for five detectors.

Human Insight AI is a Flask application for uploading a video and switching between several computer vision models without changing the interface. It can track people, classify gender and ethnicity, detect fire, and run a fight-detection model, returning annotated frames through a live MJPEG stream.

The interesting engineering decision is the model factory: each detector exposes the same prediction shape to the streaming pipeline, while the fight model gets a separate full-video path. It is a useful systems prototype, but not a production deployment yet—the repository has no benchmark suite, and the fire detector still depends on a machine-specific YOLOv5 path.

02 / About

Four years of computer vision, now moving into language models.

I did my bachelor's in AI in Pakistan, where most of my work was computer vision: segmentation, detection, tracking. My final-year project counted people in video using YOLOv8. Since then I have moved toward language models, and I am now a master's student in Applied AI at OsloMet.

The thing I keep relearning is that the model is the easy part. The fingerprint project stalled on image preprocessing for weeks. The Llama fine-tune taught me that 41 examples will change how a model sounds and nothing about what it knows. I am more interested in that gap than in the training loop.

Right now I am working on evaluation, because I have shipped too many projects where "it looks right" was the only test I ran.
